Questions, answered

Do downloads include watermarks?

TikTok publishes both a watermarked and a clean rendition of a video. PulseSave prefers the clean rendition, so the default download has no TikTok watermark. Instagram Reels and YouTube never add a watermark to the underlying file.

Why do I see a “preview data” badge?

The server runs in demo mode when yt-dlp is not installed, or when the platform blocks the server. Install yt-dlp (and optionally ffmpeg) on the host and reload — the badge switches to the live engine version automatically.

What quality can I get?

Single-file renditions (up to 1080p on most posts) work with no extra software. Installing ffmpeg unlocks merged “video + audio” streams, which is how 1440p/4K YouTube is served.

Is this legal?

Only download content you own or have permission to save, and respect each platform’s Terms of Service. See the fair-use note in the footer.
